# Laboratorio de Windows Server

## Objetivo

Este proyecto consiste en montar un laboratorio virtual
para practicar administración de sistemas y soporte IT.

## Entorno

- Hipervisor: Oracle VirtualBox
- Sistema operativo: Windows Server 2025
- Nombre del servidor: SRV-AD01

## Prácticas realizadas

- Comprobación de conectividad de red
- Resolución DNS
- Prueba de conectividad TCP al puerto 443

## Próximas prácticas

- Active Directory
- DNS y DHCP
- Recursos compartidos y permisos
- Resolución de incidencias IT
